# Fonts

The fonts of the SDK's dialogs on the `recomp` branch (the achievement toast and list, the quit prompt), embedded in
`rexui` by `src/ui/CMakeLists.txt` (`ui_fonts.h`).

| File | Font |
|---|---|
| `Barlow-Regular.ttf` | Barlow Regular (400) |
| `Barlow-SemiBold.ttf` | Barlow SemiBold (600) |
| `BarlowCondensed-Bold.ttf` | Barlow Condensed Bold (700) |

Barlow is by Jeremy Tribby (https://github.com/jpt/barlow), taken from Google Fonts (`ofl/barlow`,
`ofl/barlowcondensed`). It is under the SIL Open Font License 1.1 (`OFL.txt`), which allows embedding and
redistributing it with software; a program that ships it carries `OFL.txt` with its other licenses.
